Un agente usa skills y MCP. Un plugin los distribuye para que otro los instale con un clic.

ET21 · IA, MCP y agentes · 14

1 min. La confusión más común. Cuatro verbos: MCP conecta, skill instruye, agente ejecuta, plugin empaqueta. Un plugin no es un agente: es la caja donde vienen skills, agentes, servidores MCP y hooks para instalarlos juntos. Los que hoy están corriendo son plugins que instalé yo (Superpowers para la forma de trabajar, Playwright para el navegador). Si alguien pregunta por hooks: son scripts que corren automáticamente antes o después de una acción del agente, por ejemplo correr los tests cada vez que escribe un archivo.
