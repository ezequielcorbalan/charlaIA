ET21 · IA, MCP y agentes · 7

2 min. Antes de MCP cada herramienta se conectaba a cada IA de forma distinta, como cuando cada celular tenía su cargador. MCP (Model Context Protocol, un estándar abierto de Anthropic que adoptaron todos) es el USB-C: un programa expone sus funciones como "servidor MCP", y cualquier cliente (Claude Code, Claude Desktop, otros editores) las enchufa. Hoy vamos a usar cuatro: Blender para construir el 3D, Cloudflare para publicar, GitHub para el código y un navegador para probar la web. El agente no sabe nada especial de Blender: lee la lista de herramientas que el servidor le ofrece y las usa.
