Slide de apoyo para el agente 2. Para los de construcción: el agente no tiene un botón "plano a 3D"; lo que hace es leer la imagen como lo harían ustedes (muros, aberturas, escala), pasar eso a números y después usar Blender por MCP como si fuera un operador. El código Python que manda a Blender es el mismo que escribirían a mano. Mostrar el render final al lado del plano y señalar diferencias: la IA se equivoca, y verlo es parte de aprender a usarla.
