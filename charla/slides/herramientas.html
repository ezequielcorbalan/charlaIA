En criollo

El modelo escribe «leé index.html». Claude Code abre el archivo y le devuelve el texto. El modelo lo lee y decide el próximo paso. Nunca tocó el disco: pidió, y alguien con manos lo hizo.

ET21 · IA, MCP y agentes · 6

2 min. Esto se llama "tool use" y es la base de todo. El modelo no ejecuta nada: escribe un pedido con un formato acordado, por ejemplo "leer archivo index.html". Un programa (Claude Code, en nuestro caso) lee ese pedido, lo ejecuta de verdad y le devuelve el resultado como texto. El modelo sigue con ese resultado en la conversación. Insistir en el punto: las manos las pone el programa, no el modelo. Eso es lo que hace que sea controlable: el programa decide qué herramientas le da y cuáles pide permiso.
