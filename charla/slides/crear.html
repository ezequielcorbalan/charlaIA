5 · Cómo se hace un agente

Tres formas, de fácil a difícil

Nivel 1 · sin programar

Nivel 2 · unas líneas

Agent SDK

El motor del harness, como librería.

from claude_agent_sdk import (
  query, ClaudeAgentOptions)

async for m in query(
  prompt="Armá la web",
  options=ClaudeAgentOptions(
    allowed_tools=["Read",
      "Write","Bash"])):
  print(m)

Nivel 3 · el loop a mano

La API directa

Vos escribís el loop de la slide 9.

while True:
  r = client.messages.create(
    model="claude-opus-5",
    tools=tools,
    messages=msgs,
    max_tokens=16000)
  if r.stop_reason!="tool_use":
    break
  msgs += ejecutar(r)

ET21 · IA, MCP y agentes · 13

2 min. Nivel 1: un archivo de texto con nombre, descripción, qué herramientas puede usar y las instrucciones. Eso ya es un subagente en Claude Code; cualquiera de ustedes lo puede escribir hoy. Nivel 2: el Agent SDK es el mismo motor del harness que acabamos de ver, como librería de Python o TypeScript; con diez líneas tenés un agente con herramientas de archivos y terminal. Nivel 3: la API cruda; escribís vos el loop que vimos en la slide 9: llamás al modelo, si pide una herramienta la ejecutás y le devolvés el resultado, hasta que deja de pedir. Los tres hacen lo mismo; cambia cuánto control querés.
