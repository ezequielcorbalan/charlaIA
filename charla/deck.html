1 · Estado de la IA

De chat a agente en cuatro años

2022 – 2023

Chat

Le preguntás, te responde. Todo queda en la ventana de texto.

2024 – 2025

Copiloto

Vive adentro de tu editor. Sugiere, completa, corrige. Vos apretás el botón.

2026

Agente

Recibe un objetivo, usa programas, se equivoca, se corrige y termina el trabajo.

El cambio no es que la IA sea más inteligente. Es que ahora tiene manos.

3 · MCP: Model Context Protocol

Qué ofrece un servidor MCP

Tools

Acciones que el modelo puede pedir. Cada una tiene nombre, descripción y parámetros.

crear_pared(x, y, largo)
deployar_app(nombre)

Resources

Datos que el modelo puede leer: archivos, la escena de Blender, una tabla, un manual.

escena://objetos
docs://api/blender

Prompts

Recetas listas para tareas comunes, escritas por quien hizo el servidor.

"armá una casa desde
este plano"

Lo que vamos a usar hoy del servidor de Blender

get_objects_summary · execute_blender_code · render_viewport_to_path

4 · Agentes

Anatomía de un agente

Instrucciones

Quién es, cómo trabaja, qué estilo tiene. Un texto que se escribe una vez.

Herramientas

Qué puede tocar: archivos, terminal, servidores MCP. Menos es mejor.

Memoria

La conversación, más archivos donde anota lo que aprende para la próxima.

Permisos

Qué hace solo y qué pregunta antes. Borrar o publicar siempre se pregunta.

Un agente bueno no es el que hace de todo. Es el que tiene una tarea clara, pocas herramientas y límites.

5 · El harness

El modelo es el motor. El harness es el auto

El modelo

Predice la próxima palabra. No sabe qué archivo abriste ni qué pasó hace diez minutos.

El harness

El programa que lo envuelve. Arma el pedido, ejecuta las herramientas y hace que todo esto sea usable.

Claude Code, OpenCode, Cursor, Codex y Aider son harnesses. El modelo puede ser el mismo y el resultado cambia.

Qué hace, que el modelo no hace

Arma el pedido. Decide qué entra en la conversación y en qué orden.

Maneja el contexto. Cuando se llena, resume lo viejo para no perder el hilo.

Ejecuta las herramientas y le devuelve el resultado al modelo.

Aplica los permisos. Qué corre solo y qué te pregunta antes.

Pone la interfaz, el historial y el botón de frenar.

5 · Cómo se hace un agente

Tres formas, de fácil a difícil

Nivel 1 · sin programar

Un archivo Markdown

Claude Code lo lee y ya existe el agente.

.claude/agents/web.md
---
name: web
description: Arma sitios
tools: Read, Write, Bash
---
Sos un dev frontend.
Usá HTML y CSS simples.

Nivel 2 · unas líneas

Agent SDK

El motor del harness, como librería.

from claude_agent_sdk import (
  query, ClaudeAgentOptions)

async for m in query(
  prompt="Armá la web",
  options=ClaudeAgentOptions(
    allowed_tools=["Read",
      "Write","Bash"])):
  print(m)

La API directa

Vos escribís el loop de la slide 9.

while True:
  r = client.messages.create(
    model="claude-opus-5",
    tools=tools,
    messages=msgs,
    max_tokens=16000)
  if r.stop_reason!="tool_use":
    break

5 · Cómo se trabaja con agentes

SDD: primero la spec, después el código

1 · Preguntar

Brainstorm

Solo lo que no puede decidir solo.

2 · Spec

Qué y por qué

Objetivo, límites y criterio de éxito.

3 · Plan

Pasos chicos

Cada uno con su prueba.

4 · Código

Recién ahora

Contra la spec, no contra lo que adivina.

5 · Verificar

Evidencia

Tests, capturas, renders.

Por qué es lo más usado hoy

Un agente rápido con un pedido vago produce mucho código equivocado, muy rápido. La spec es el contrato: lo que ustedes saben, escrito antes.

Hoy lo van a ver

Los dos agentes usan el plugin Superpowers: preguntan, escriben la spec, planifican, construyen y verifican. Miren la lista de muros antes del primer muro.

Cierre

Qué significa esto para ustedes

Computación

El trabajo ya no es tipear código: es saber qué pedir, revisar lo que vuelve y entender por qué funciona. Quien sabe programar le saca diez veces más al agente que quien no.

Construcción

Planos, cómputos, modelos y presupuestos se van a hacer con estas herramientas. El que conoce la obra es el que puede decir si lo que hizo la IA está bien o mal.

Cómo empezar hoy

1

Instalen un agente de código y pídanle que les explique un proyecto que ya tengan.

2

Escriban un agente de nivel 1: un archivo Markdown con una tarea chica y clara.

3

Revisen todo lo que produce. La IA se equivoca con mucha seguridad; el criterio lo ponen ustedes.
